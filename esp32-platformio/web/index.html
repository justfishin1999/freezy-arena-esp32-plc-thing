Network and Arena connection

Saves reboot device

Read-only Freezy Arena WebSocket. Match mode uses the public Arena API; robot and readiness modes use the existing Field Monitor stream (the ESP32 appears as ESP32-Field-Light in FMS Displays).

Field monitoring mode

If FMS connectivity is lost, both lamps turn off. If FMS is connected but detailed status is unavailable, the light shows red until valid readiness information arrives. Empty stations are ignored for robot connectivity. E-stopped stations do not count as ready.

Horner analog input interface

WIRING: ESP32 GND to PLC 0V, heartbeat GPIO26 to A1, running GPIO27 to A2. PLC A1/A2 physical jumpers and Cscape settings MUST be 0–10 V voltage mode. Never connect PLC 24 V to ESP32 GPIO. GPIO33 is reserved for password recovery.

Management access

Local password

For forgotten credentials, hold GPIO33 low for 10 seconds while watching Serial Monitor. This rotates both the web password and setup AP password but keeps field settings.

Firmware update over Wi-Fi

Version —

Upload the compiled firmware.bin file from PlatformIO (.pio/build/esp32dev/firmware.bin). The device verifies and installs the update in its OTA partition, then reboots.

During firmware updates, both ESP32 PLC signals go LOW; the Horner watchdog releases the outputs. Keep the device powered and on a trusted network. Never upload a ZIP file or an untrusted firmware image.
